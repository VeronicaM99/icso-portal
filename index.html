Conectar base de datos
Sigue estos pasos para conectar Supabase y que los clientes se guarden en la nube.
1
Crea una cuenta gratuita en Supabase
Ve a supabase.com → "Start your project" → regístrate con GitHub o email. Es completamente gratis.
2
Crea un proyecto nuevo
Ponle cualquier nombre (ej. "icso-portal"), elige una región cercana (Europe West) y una contraseña de base de datos.
3
Crea la tabla de clientes
En el menú izquierdo ve a SQL Editor y ejecuta este código:

CREATE TABLE clients ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, "user" text UNIQUE NOT NULL, pass text NOT NULL, name text, projects text[] DEFAULT '{}', created_at timestamptz DEFAULT now() ); ALTER TABLE clients ENABLE ROW LEVEL SECURITY; CREATE POLICY "anon_all" ON clients FOR ALL TO anon USING (true) WITH CHECK (true);
4
Copia tus credenciales aquí
En Supabase ve a Settings → API y copia la URL del proyecto y la clave anon/public.
